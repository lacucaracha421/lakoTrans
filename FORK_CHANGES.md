# 포크 운영 안내 (lakotrans)

원본 [ucx0204/CarrotMangaTranslator](https://github.com/ucx0204/CarrotMangaTranslator)를
따라가면서 불편한 부분만 개조하는 포크입니다. 원본은 GPL-3.0이므로 이 포크도 GPL-3.0을
따르며, 배포할 때는 수정한 소스도 함께 공개해야 합니다.

## 브랜치 규칙

| 브랜치   | 역할                                                       |
| -------- | ---------------------------------------------------------- |
| `master` | 원본 `master`의 **완전한 복사본**. 직접 커밋하지 않습니다. |
| `main`   | 개조판(기본 브랜치). 모든 개조는 여기로 들어옵니다.        |

- `.github/workflows/upstream-sync.yml`이 매일 원본을 받아 `master`를 갱신하고,
  `master → main` PR을 엽니다. PR은 **merge commit**으로 합칩니다.
- 충돌이 나면 `main`에서 새 브랜치를 만들어 `master`를 merge하고 거기서 해결합니다.
- 원본이 워크플로 파일을 바꾸면 기본 토큰으로는 push가 막힙니다. 그때는 이슈가 열리니
  `master` 브랜치 화면의 **Sync fork** 버튼을 누르거나, `UPSTREAM_SYNC_TOKEN` 시크릿
  (fine-grained PAT: 이 저장소의 Contents·Workflows·Pull requests 쓰기)을 등록합니다.

## 설치 파일 만들기

Actions → **Fork Build (Windows)** → **Run workflow**(브랜치 `main`)를 실행하면 약
20~40분 뒤 실행 결과 화면 아래 **Artifacts**에서 서명되지 않은 Setup EXE를 받을 수
있습니다. 태그나 릴리스는 만들지 않으며 파일은 14일 보관됩니다. 앱 ID가 공식판과 같아
설치하면 기존 설치를 덮어쓰고 데이터 폴더를 그대로 사용합니다.

## 번역 속도 추적 기록

번역할 때마다 앱 로그 폴더(`<데이터 폴더>/logs`)의 `translation-trace.jsonl`에 한 줄씩
JSON 기록이 쌓입니다. 16 MiB를 넘으면 `translation-trace.jsonl.1`로 넘기고 새로 씁니다.
원문·번역문·이미지 내용은 쓰지 않고 크기·개수·시간만 남깁니다.

| `type`            | 내용                                                                                                                       |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------- |
| `endpoint-start`  | 모델 서버(로컬 llama·API·Codex) 시작에 걸린 시간                                                                           |
| `model-request`   | HTTP 요청 1회: 걸린 시간, 프롬프트 글자 수·이미지 수·크기, 출력 글자 수, llama 프롬프트 처리/생성 토큰·시간, API 사용 토큰 |
| `api-pacing-wait` | API 요청 간격 제한으로 기다린 시간(50 ms 이상만)                                                                           |
| `api-retry`       | API 키 재시도와 대기 시간                                                                                                  |
| `page-attempt`    | 페이지 번역 시도 1회의 전체 시간과 성공 여부·실패 분류                                                                     |
| `page-context`    | 페이지 뒤 누적 문맥 크기(용어·인물·말투 지정 인물·스토리 페이지 수)                                                        |

모든 줄에 앱 메모리(`rssMb`)와 시스템 남은 메모리(`freeMemMb`)가 함께 기록됩니다.

## 개조 원칙

- 원본 파일 수정은 최소한으로 하고, 새 동작은 가능한 한 새 파일에 둡니다.
- 원본 파일을 고칠 때는 아래 목록에 파일과 이유를 적어, 원본이 같은 문제를 고치면
  우리 개조를 쉽게 걷어낼 수 있게 합니다.
