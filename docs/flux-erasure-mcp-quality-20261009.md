## 기타 MCP와 DeepSeek

기타 클라이언트는 ChatGPT·Claude·Anthropic을 제외한 이름으로 분류하며 기본 효과음
범위는 원문 보존이다. 도구 권한이나 정밀 완료 기준을 제품 이름에 따라 완화하지 않는다.

- `omitText: true` 원문 제거 결과를 전체 페이지와 crop으로 조회할 수 있다. 식자 렌더와
  분리해 후리가나·마지막 글자·새로 생긴 선·얼룩을 확인한다.
- 감지된 말풍선 영역을 일반 블록 수정으로 실수로 덮어쓰지 않도록 보호한다. 명시적
  override는 유지하지만 오류를 피하려고 override하라는 지침은 주지 않는다.
- 실제 한국어 줄 분리, 말풍선 윤곽 양쪽, 폰트 굵기와 독서 크기, 전체 요청 범위를 함께
  검수하도록 공용 기타 지침을 보강했다.
- 균일한 원본 배경의 작은 결함은 기존 색상 샘플·paint preview·mask 확인·apply 경로로
  보정하도록 안내한다. 무늬를 흰색으로 덮거나 원문 잔여를 한국어로 가리지 않는다.

실제 `opencode-go/deepseek-v4.1-flash`, `high`, 최초 요청 `이 화 번역해줘.`로
동일한 고정 한 페이지를 독립 data root에서 반복했다. ImageGen과 생성 한글 획 보정은
제외했다. `carrot-balloon-high-03`은 native 검수가 수락됐어도 내레이션 아래 회색 사선을
놓쳐 시각 검수 실패다.

04는 그 얼룩이 없어지고 이름의 글자 분리를 스스로 수정했으나, 상단 검은 점을 놓쳤다.
우하단 연결 말풍선을 합쳐 배치하고 “있으면 싶었는데”라는 어색한 번역도 남겼다.
검수 제출에서 잘못된 JSON과 검수 조건 오류를 11차례 반복해 해당 시험 프로세스만
중단했다. 실제 렌더와 실패 기록을 보존했으며, 이 실행을 완료로 판정하지 않았다.

05에서는 빈 페이지에 로컬 OCR을 우선하고 문장과 연결 말풍선 분리를 다시 확인하라는

작성했고, 제외된 효과음 3개도 번역하려 했다. 이 실행을 중단하고 **실험용 지침을
되돌렸다.** 지침 강화만으로 개선됐다고 주장하지 않는다. `rejected-guidance.ts`와
`visual-assessment.json`에 실패를 보존했다. 세 실행 모두 사용자 원본·작품·화 SHA를
별도로 확인했다.
