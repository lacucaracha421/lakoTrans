# 당근망가번역기 MCP: 한국어 말풍선 식자

이 규칙은 당근망가번역기(Carrot)의 MCP로 만화를 번역·식자·검수할 때만 적용한다. 다른 코딩 작업의 행동이나 권한을 바꾸지 않는다. 사용자의 현재 요청과 앱의 정밀 번역 가이드를 함께 따른다.

## 말풍선의 물리적 칸을 먼저 읽기

- 전체 원본을 보고 화자·읽는 순서를 이해한 뒤, 말풍선 안에서 실제로 글자를 담을 수 있는 각 칸을 구분한다. 원문 세로열 하나가 한국어 블록 하나인 것은 아니다.
- 두 원형 풍선이 좁은 목으로 이어진 모양, 위아래로 불룩한 모양은 같은 화자의 한 문장이어도 별도의 식자 영역이다. 위 칸의 짧은 감탄사와 아래 칸의 긴 말을 한 직사각형 텍스트 상자로 합치지 않는다. 빈 줄이나 큰 행간으로 두 칸을 흉내 내지 않는다.
- 붙어 있는 풍선을 합친 기존 블록은 MCP의 블록 편집으로 나누고 각 칸에 해당하는 원문·번역문을 연결한다. 분리하면서 문구를 빠뜨리거나 중복하지 않는다. 원문 좌표와 한국어 표시 좌표를 구분한다.
- renderBbox와 페이지 경계 안에 들어갔다는 사실은 말풍선 안에 들어갔다는 뜻이 아니다. 둥근 테두리, 좁은 목, 꼬리, 인물의 머리카락, 패널 경계를 보고 실제 글자의 잉크가 풍선의 안전한 내부에 있도록 배치한다. 테두리에 닿는 줄이 없는지 각 줄의 양끝을 확인한다.

## 좌표와 읽기 편한 크기

- 원본 이미지 크기, 반환된 미리보기 크기, crop의 원점·배율을 먼저 확인한다. 축소 이미지에서 읽은 좌표를 원본 픽셀인 것처럼 전달하지 않는다. 실제 도구 계약의 pixel/normalized_1000 구분을 따른다.
- 일반 한국어 대사는 가로쓰기를 기본으로 한다. 좁은 원문 세로열을 그대로 답습하지 않는다. 이미 선택한 작품 폰트 팔레트와 강조 차이를 유지한다.
- 풍선 모양에 맞는 표시 영역, 의미를 보존한 문구, 자연스러운 줄바꿈을 먼저 조정한다. 맞지 않는 결과를 일괄 축소하거나 납작하게 만들어 해결하지 않는다. 풍선을 나눴다면 각 칸의 공간과 감탄사·본문의 역할에 맞춰 크기를 정한다.
- 한 음절짜리 어미·조사, 고립된 문장부호, 이름·호칭의 부자연스러운 분리를 수정한다. 실제로 독립된 짧은 발화와 의도적인 말줄임표는 유지할 수 있다. 수정 가능한 불량 줄바꿈을 검수 통과 목적으로 '의도적'이라 설명하지 않는다.

## 실제 합성 결과로 검수

- 처음부터 이미지를 보며 판단한다. OCR 목록과 수치만으로 말풍선 형태를 판단하지 않는다. 변경 후 현재 revision의 실제 페이지 렌더와 문제 풍선의 crop을 다시 열어 본다.
- 연결된 풍선은 위·아래/좌·우 각 칸의 중심, 줄별 좌우 여백, 좁은 목 주변, 마지막 줄의 위치를 따로 확인한다. 한 칸이 비어 있고 다른 칸이나 그림 위에 글자가 몰리면 미완료다. crop만 보지 말고 일반 독서 배율의 전체 페이지에서도 크기와 흐름을 확인한다.
- 길고 좁은 풍선에 여러 줄을 넣었거나, 아래로 좁아지는 풍선에 긴 문장이 있으면 수치상 overflow가 없어도 우선 검수 대상이다. 마지막 수정 뒤 풍선 전체와 주변 그림이 함께 보이는 최종 render crop을 반드시 열어 각 줄의 양끝을 확인한다. 전체 페이지를 작게 본 것만으로 통과시키지 않는다.
- 텍스트 상자의 중심이 실제 풍선 내부의 중심이라고 가정하지 않는다. 아래로 갈수록 오른쪽 테두리가 안쪽으로 들어오는 풍선에서는 아래 행의 끝이 특히 쉽게 밖으로 나온다. 긴 마지막 줄과 그 위 두세 줄을 각각 확인하고, 실제 내부로 문단을 이동하거나 의미 단위로 줄을 다시 나눈다. 보이는 침범을 '의도적' 예외로 처리하지 않는다.
- 수치상 overflow=false, 서버 검수 accepted, 원문 제거 완료만으로 시각적 품질을 통과시키지 않는다. 글자가 그림에 걸리거나 테두리를 침범하면 해당 블록을 수정하고 다시 렌더한다. 서버가 미적 판단을 대신한다고 설명하지 않는다.
- 이미 괜찮은 영역은 유지하고 발견한 문제만 고친다. 사용자가 이미지 작업을 제외했다면 식자를 수정하며 FLUX/ImageGen/붓 보정으로 배경을 바꾸지 않는다. 해결하지 못한 항목은 완료로 제출하지 말고 페이지와 문제를 명시한다.
- 정밀 완료 증거는 앱의 현재 가이드와 MCP 절차로 제출한다. 로컬 저장 JSON 직접 편집, 검수 기록 조작, 권한 우회로 작업을 끝내지 않는다.
