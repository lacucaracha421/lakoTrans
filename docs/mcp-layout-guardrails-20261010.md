Codex·codex_cli_rs·OpenAI 연결 이름을 기타로 보내던 분류 오류를 수정했다.
이 연결에는 기타 전용 지침·효과음 원문 보존 기본값·추가 배치 경고를 적용하지 않는다.
명시적인 효과음 처리 요청과 공용 도구·권한·검수 계약은 유지한다.
딥시크에서 확인한 실패를 바탕으로 기타 가이드만 조정한다.
사용자 지시는 기본 가이드보다 우선하며, LLM이 번역·폰트·크기·배치를 자율적으로 판단한다.
새 실행 루프, 모델별 편집 엔진, C23 변경, FLUX 후처리 변경은 없다.

- 기존 기타 가이드의 반복 지시를 정리하고 원문/문맥, 원문 크기 분석·폰트 견본,
  geometry-only 제안, 배경 검사, 실제 렌더 비교, 기존 검수의 순서로 안내한다.
- 검출과 문장 줄바꿈을 분리한다. 검출이 틀렸거나 사용자 의도가 다르면 수동 배치와
  기존 `allowDetectedLayoutOverride`를 사용할 수 있다. 세로쓰기·회전·작은 글씨를 금지하지 않는다.
- API가 제공하지 않는 per-line ink 좌표를 요구하던 문구를 제거한다.
- 기타의 효과음 기본값은 원문 보존이다. 명시적인 `soundEffectScope`는 기본값보다 우선한다.
  이는 안내의 기본값이며 도구 사용 금지가 아니다.
- 실제 PageArtwork 계측의 `shapeFlow`는 현재 렌더가 유효한 shape slot을 사용했는지 보여준다.
  `contained`는 실제 원화 윤곽을 정확하게 검출했다는 보장이 아니며,
  `unverified`는 수동 배치 금지나 검수 자동 탈락을 뜻하지 않는다.
- 이번에 시도한 shapeFlow 필수화·작은 글씨 강제 차단·단어 분리 강제 차단과
  사용자 예외 신청 계약은 철회했다. 기존 상세 검수 계약과 편집 기능은 유지한다.

최종 가이드의 품질 개선 근거로 사용하지 않는다. 사용자 보관함·원본·출력은 보존했다.

## 평가 조건 오류와 재검증 범위

기존 4작품 8페이지 평가본은 원본 이미지만 가져오면서 저장 블록과 배치도 제외했다.
원본 보관함에는 블록 44개, 말풍선 배치 정보 43개가 있었으므로 이 시험은

결과를 기존 배치 보존 경로의 품질로 해석하지 않는다.

시간은 같은 출발점의 개선 비교로 취급하지 않는다. 기타 지침은 저장 영역을 먼저
읽고 번역·폰트·크기·줄바꿈만 바꿀 때 `renderRect`를 생략하도록 보강했다.
