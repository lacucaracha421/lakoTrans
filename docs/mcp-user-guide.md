# MCP 연결·사용 가이드

당근의 MCP 서버는 실행 중인 앱의 보관함·편집·처리·출력 기능을 외부 AI에 제공합니다. **당근 앱과 Tailscale이 서버 역할**, Codex·ChatGPT·Claude·Claude Code가 작업을 요청하는 클라이언트 역할을 합니다. 앱에서 저장된 결과를 확인하고 직접 수정할 수 있습니다.

## 1. 당근에서 연결 준비

1. 당근을 실행하는 PC에 [Tailscale](https://tailscale.com/download)을 설치합니다.
2. Tailscale에서 **Log in → 브라우저 로그인 → Connect**로 PC를 연결합니다. Windows는 시계 옆 트레이 아이콘, macOS는 메뉴 막대에서 상태를 확인합니다.
3. 당근의 **설정 → AI 앱 연결 (MCP)**에서 **MCP 켜기**를 누릅니다.
4. **Tailscale에서 연결 허용**이 나타나면 브라우저에서 HTTPS·Funnel 사용을 허용한 뒤 MCP를 다시 켭니다. 계정 관리자가 별도로 허용해야 하는 환경도 있습니다.
5. **연결 가능** 상태에서 **연결 방법 및 도움말 → 연결 진단**을 실행합니다.
6. **주소 복사**로 `https://…ts.net/mcp` 전체를 복사합니다. 아래에서 사용하는 `<복사한 MCP 주소>`를 이 값으로 바꾸세요.

![MCP 설정과 권한](images/readme-current/mcp.png)

**Tailscale Funnel은 PC의 MCP 접속 주소를 인터넷에 공개합니다.** 도구 호출은 OAuth 인증과 당근 앱의 승인을 거쳐야 합니다. 주소를 복사하는 것만으로 승인이 끝나지는 않습니다. 같은 기기·네트워크 이름을 유지하면 주소를 재사용할 수 있으며, 이름 변경이나 기기 재등록 후에는 다시 확인해야 합니다.

연결 진단은 공개 주소·인증 안내·무인증 요청 차단을 확인합니다. 모델을 실행하지 않으며, 진단 성공과 AI 클라이언트의 로그인·파일 다운로드 성공은 별도로 확인합니다. Tailscale의 전체 공유 설정을 초기화하거나 별도 Funnel 명령을 실행할 필요는 없습니다.

## 2. AI 클라이언트 등록

### Codex 앱·CLI

![당근 설정의 Codex 등록 명령과 승인 안내](images/readme-current/mcp-codex.png)

Codex CLI가 설치된 PC의 터미널에서 실행합니다. 당근 설정의 **연결 방법 및 도움말 → Codex → 명령 복사**를 쓰면 현재 주소가 채워집니다.

```sh
codex mcp add carrot --url "<복사한 MCP 주소>"
codex mcp login carrot
```

브라우저가 열리면 당근 설정에 표시된 숫자 코드와 요청 권한을 비교하고 **당근에서 승인**합니다. 같은 PC의 Codex 앱·CLI는 MCP 설정을 공유합니다. 연결 후 새 작업을 열고 당근 도구가 보이는지 확인하세요. [공식 MCP 안내](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)

### ChatGPT

![당근 도움말의 ChatGPT 플러그인 등록 화면](images/readme-current/mcp-chatgpt.png)

1. 필요하면 **설정 → Security and login → Developer mode**를 켭니다. 계정·워크스페이스 정책에 따라 메뉴가 제한될 수 있습니다.
2. 왼쪽 **플러그인 → 추가 → MCP 앱 만들기**에서 이름을 `당근망가번역기`로 입력합니다.
3. 연결 주소에 복사한 `/mcp` URL을 넣고 인증은 **OAuth**를 선택합니다. 고급 OAuth 설정은 기본값을 유지합니다.
4. 만들기를 누르고 브라우저·당근의 코드와 권한을 확인한 뒤 당근에서 승인합니다.
5. 새 대화에 당근 연결을 추가하고 요청합니다.

업데이트 후 새 도구가 안 보이면 연결의 **Refresh**로 목록을 갱신하고 새 대화에서 확인합니다. 메뉴 표시는 클라이언트 버전에 따라 달라질 수 있습니다. [공식 연결 안내](https://developers.openai.com/plugins/deploy/connect-chatgpt)

### Claude 웹·앱

![당근 도움말의 Claude 커스텀 커넥터 등록 화면](images/readme-current/mcp-claude.png)

1. 이름 메뉴의 **설정 → 커넥터**를 엽니다. 버전에 따라 **Customize → Connectors**에 있습니다.
2. **추가 → 커스텀 커넥터 추가**에서 이름과 복사한 MCP 주소를 입력합니다.
3. 자동으로 감지된 로그인·등록 방식을 유지해 추가합니다. 별도의 요청 헤더나 직접 만든 Client ID·Secret은 필요하지 않습니다.
4. **연결**을 누르고 브라우저·당근의 코드와 권한을 확인한 뒤 당근에서 승인합니다.
5. 새 대화의 도구 메뉴에서 당근을 켜고 요청합니다.

당근 설정의 **연결 방법 및 도움말 → Claude**에서 단계별 화면을 볼 수 있습니다. [공식 커스텀 커넥터 안내](https://support.claude.com/en/articles/11175166-get-started-with-custom-connectors-using-remote-mcp)

### Claude Code

![당근 설정의 Claude Code 명령과 인증 순서](images/readme-current/mcp-claude-code.png)

Claude Code가 설치된 터미널에서 등록합니다. `--scope user`는 현재 사용자 계정의 모든 프로젝트에서 사용할 수 있게 하는 옵션입니다.

```sh
claude mcp add --transport http --scope user carrot "<복사한 MCP 주소>"
```

Claude Code 안에서 **`/mcp` → carrot → Authenticate**를 선택합니다. 브라우저·당근의 코드와 권한을 확인해 승인한 뒤 새 대화에서 사용합니다. [공식 MCP 안내](https://code.claude.com/docs/en/mcp)

## 3. 작업 요청

먼저 조회로 연결을 확인합니다.

> 당근 보관함의 작품과 화 목록을 보여줘. 아직 수정하지 마.

그다음 **작품·화·페이지 범위, 처리할 내용, 유지할 내용, 출력 형식**을 지정합니다. AI가 최신 상태와 사용 가능한 도구를 조회하므로 블록 ID나 파일 경로를 직접 알아둘 필요는 없습니다.

| 목적        | 요청 예시                                                                                                        |
| ----------- | ---------------------------------------------------------------------------------------------------------------- |
| 번역·식자   | 「작품명」 2화 1~3페이지를 한국어로 번역해줘. 1화의 용어·말투를 참고하고 효과음까지 처리한 뒤 렌더링을 검수해줘. |
| 번역문 교정 | 1화에서 인물 A의 번역문만 존댓말로 통일해줘. 원문·위치·서식은 유지하고 변경 전후를 보여줘.                       |
| 식자 보정   | 3페이지의 넘치는 대사만 줄바꿈과 크기를 조정해줘. 수정 후 원본과 같은 배율로 확인해줘.                           |
| 원문 제거   | 선택한 페이지에서 대사 영역의 원문을 지워줘. 번역문과 다른 그림은 유지해줘.                                      |
| 출력        | 2화의 저장된 결과를 PNG로 출력해서 ZIP 다운로드 파일을 줘. 미완료 페이지가 있으면 알려줘.                        |

**“로컬 모델은 사용하지 마”**, **“당근에 설정한 번역 엔진으로 실행해줘”**, **“수정 전에 변경안을 보여줘”**처럼 실행 조건도 붙일 수 있습니다. 실제 사용 가능 여부는 연결 권한·앱 모델 준비·클라이언트 도구 지원에 따라 결정됩니다.

### 기본 번역과 완료 기준

작품과 화가 정해져 있으면 **“이 화 번역해줘”**로 요청할 수 있습니다. 전체 번역의 기본은 정밀 작업입니다. 원본에서 대사·작은 글씨·효과음을 확인하고, 실제 한국어 폰트 견본과 작품 팔레트, 읽기 편한 크기·줄바꿈, 최종 렌더를 함께 검수합니다. 보통 5페이지 이하씩 진행하고 마지막에는 요청한 전체 범위의 완료 상태를 확인합니다. “빠르게 처리해줘”라고 명시한 간소화 작업은 정밀 검수 완료로 표시하지 않습니다.

생성 효과음은 원문 제거와 한국어 글자 생성을 따로 확인합니다. **OCR이 의도한 단어를 맞혀도 자음·모음·받침의 모양이나 배치가 잘못되면 정밀 완료를 승인하지 않습니다.** 기본 번역에서는 AI가 획을 반복해서 칠하거나 자모를 옮기지 않습니다. 사용자가 조금 고치면 쓸 수 있는 결과는 원래 이미지와 확정 문구를 보존하고, 대상과 문제를 명시해 **사용자 보정 대기**로 남깁니다. 번역과 일반 식자는 계속 진행하되 보정 대기를 완료로 표시하지 않습니다. AI에게 직접 보정을 요청한 경우에는 보정한 실제 합성 결과를 다시 검사합니다. 생성 결과를 일반 폰트로 대체했다면 대상과 이유를 함께 반환합니다.

현재 저장 상태의 원본 확인·폰트 선택 근거·최종 렌더·생성 글자 검사가 빠졌거나 오래됐으면 미완료입니다. 이 기준은 검수 근거를 확인하는 장치이며, AI의 미적 판단이나 모든 오자의 검출을 보장하지는 않습니다. [구현과 실제 시험 기록](mcp-translation-quality-v2-20261008.md)을 참고하세요.

### 생성 효과음의 일부만 옮기기

AI에게 “이 효과음의 어긋난 자모만 옮겨 고치고, 한글 모양과 최종 배치를 다시 확인해줘”라고 요청할 수 있습니다. 편집기에서도 직접 조정할 수 있습니다.

1. 생성 효과음 블록을 선택하고 **효과음 보정 → 부분 이동**을 고릅니다.
2. **자유 선택** 또는 **사각 선택**으로 옮길 획을 둘러쌉니다.
3. 선택 영역 안쪽을 끌어 이동합니다. 방향키는 원본 페이지 기준 1px, Shift+방향키는 10px씩 조정합니다.
4. **적용 / Enter**로 저장하거나 **취소 / Escape**로 미리보기를 취소합니다. 적용한 이동은 기존 Undo/Redo로 되돌릴 수 있습니다.

원본 생성 이미지는 유지됩니다. 이동한 뒤 추가 붓 보정을 할 수 있으며, 이동 자체를 되돌릴 때는 Undo를 사용합니다. 앱을 업데이트한 뒤 새 기능이 보이지 않으면 편집 내용을 저장하고 앱을 다시 실행한 후 연결된 AI의 도구 목록을 갱신하세요.

### AI가 작성하는 번역과 앱 모델 실행

| 방식                                    | 실행 주체·비용                                                                                                |
| --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 연결한 AI가 원문을 읽고 번역문을 저장   | 현재 Codex·ChatGPT·Claude의 모델과 이용 한도 사용. 번역문 저장 자체가 당근의 번역 모델을 추가 실행하지는 않음 |
| AI가 당근의 OCR·번역·이미지 처리를 요청 | 당근에 설정된 모델·장치·계정 사용. 외부 엔진이면 해당 제공자에게 데이터 전송 및 이용 한도·요금 적용           |
| 폰트 조회·서식 수정·저장된 결과 출력    | 해당 앱 도구 실행. 이 작업 자체는 번역 모델을 실행하지 않음                                                   |

MCP 연결만으로 이미지 생성 도구가 새로 제공되는 것은 아닙니다. 연결한 AI의 이미지 도구가 생성 파일을 전달할 수 있거나, 당근의 이미지 엔진이 준비되어 있어야 해당 경로를 사용할 수 있습니다.

### 지원 작업 범위

- **읽기·검수:** 보관함·페이지·블록 검색, 원본과 부분 이미지, 실제 앱 렌더링, 검수 상태.
- **번역·구조:** OCR·번역 실행, 기존 번역문 수정, 블록 생성·영역·읽기 순서 편집, 다중 페이지 작업.
- **식자·보정:** 폰트 목록·견본, 자동 크기·폰트 분석, 텍스트·서식·배치 일괄 적용, 원문 제거·마스크·이미지 수정, 효과음.
- **문맥·자료:** 용어집·인물·규칙·장면 기억, 인터넷 조사와 제안 적용, 파일·웹 원고 가져오기, 작품·화·페이지 관리.
- **출력·교환:** PNG·JPEG·WebP·PSD, ZIP, `.mgtshare`, 텍스트·검수표·문맥 파일, 연결된 결과 폴더 동기화.

작품·화·페이지 삭제와 구조 변경도 관리 권한에 포함됩니다. 대상을 명확히 지정하고 유지할 작업은 먼저 내보내세요. 도구별로 미리보기·최신 상태 확인·적용 절차가 있으며, 모든 작업이 한 번의 호출로 완료되는 것은 아닙니다.

### 저장·완료·다운로드 확인

편집 전에 앱의 미저장 내용을 저장하고, 같은 페이지에서 실행 중인 작업을 마칩니다. MCP는 최신 페이지 상태를 기준으로 변경하며, 그사이 페이지가 바뀌면 충돌로 중단할 수 있습니다. 최신 내용을 다시 읽고 재적용해야 합니다.

긴 작업의 **접수**는 **완료**가 아닙니다. AI에게 완료·실패·미처리 페이지를 확인하도록 요청하세요. 출력도 작업 완료 후 **파일 조회·다운로드**가 필요합니다. 채팅에 링크가 없으면 “완료한 출력 파일의 다운로드 링크를 줘”라고 요청하면 됩니다. 만료된 링크는 보존된 출력이 유효한 경우 재발급할 수 있습니다.

PSD는 원본 배경을 포함하며 복잡한 식자는 래스터 레이어로 보존될 수 있습니다. 원고를 포함한 파일·다운로드 링크의 공유 범위를 확인하세요. 이미지 전송 권한과 가리기 상태에 따라 제공이 제한될 수 있습니다.

## 4. 권한과 연결 관리

![앱 이름·숫자 코드·요청 권한을 확인하는 승인 화면](images/readme-current/mcp-approval.png)

| 앱 설정                               | 허용 범위                                                                      |
| ------------------------------------- | ------------------------------------------------------------------------------ |
| 기본 조회                             | **보관함 전체**의 텍스트·문맥 조회와 텍스트 파일 출력                          |
| **이미지·출력 파일 전송**             | 원본·미리보기·이미지를 포함하는 출력 파일 전송                                 |
| **텍스트·서식·문맥 편집**             | 번역문·서식·용어·기억 등 저장 내용 변경                                        |
| **블록·보관함 관리 및 OCR·번역 실행** | 블록·보관함 구조 관리와 앱 모델 처리. 도구에 따라 편집·이미지 권한도 함께 필요 |
| **앱 시작 시 자동 연결**              | 당근 실행 시 MCP 시작. 새 클라이언트의 승인을 대신하지 않음                    |

처음 사용하는 데이터 폴더에서는 위 선택 항목이 켜져 있습니다. 필요한 범위로 조정한 뒤 연결하세요. 기존에 저장한 선택은 유지됩니다. 현재 권한은 작품별로 제한하는 방식이 아닙니다.

- **권한 변경:** 즉시 적용되며 진행 중인 작업이 취소되고 재승인이 필요합니다.
- **MCP 끄기:** 서버 접속을 중단합니다. 저장된 클라이언트 승인은 유지됩니다.
- **연결 해제:** 해당 AI 앱의 접근·갱신 권한을 철회합니다. 다시 사용하려면 재연결·승인이 필요합니다.
- **승인 보관:** 승인 정보는 운영체제 암호화 저장소에 보관됩니다. 장기 미사용·철회·주소 변경 후에는 다시 인증해야 할 수 있습니다.

클라이언트의 “도구 실행 확인” 설정은 당근의 연결 권한과 별개입니다. 확인 없이 실행하도록 설정하면 편집·삭제도 질문 없이 진행될 수 있지만, 당근에서 허용하지 않은 권한까지 추가되지는 않습니다.

## 5. 문제 해결

| 증상                                     | 조치                                                                                                            |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Tailscale 설치·로그인 오류               | PC의 Tailscale 앱에서 로그인과 **Connect** 상태 확인. 웹사이트 로그인만으로는 부족                              |
| HTTPS·Funnel 권한 오류                   | 당근에 표시된 허용 링크에서 완료. 조직 계정이면 네트워크 관리자 확인                                            |
| 443 사용 중                              | 다른 당근 인스턴스의 MCP 또는 다른 앱의 공유 사용 여부 확인. 기존 공유가 끝난 뒤 재시도                         |
| 주소가 있지만 연결되지 않음              | **연결 가능** 상태인지 확인. 꺼진 서버도 이전 주소를 표시할 수 있음. 최초 연결 직후라면 DNS 반영 후 진단 재시도 |
| 승인 요청 만료·코드 불일치               | 연결하는 클라이언트에서 인증을 다시 시작하고 새 코드 비교                                                       |
| 읽기는 되지만 편집·이미지·처리 불가      | 필요한 앱 권한과 해당 클라이언트의 승인 범위 확인 후 재승인                                                     |
| 업데이트 후 도구가 없거나 옛 설명이 보임 | 당근 재시작 → 클라이언트 도구 목록 갱신 → 새 대화. ChatGPT는 연결의 **Refresh** 사용                            |
| 페이지 사용 중·미저장 편집·revision 충돌 | 앱에서 저장·작업 완료 후 최신 페이지를 다시 읽고 요청                                                           |
| 이미지 전송·출력 차단                    | 이미지 권한과 해당 페이지의 가리기 검토 상태 확인                                                               |
| 모델을 실행할 수 없음                    | 당근 설정의 로그인·API 키·모델·장치 및 OCR/모델 확인                                                            |
| 출력 완료인데 첨부파일이 없음            | 완료 상태와 실제 출력 파일 조회를 요청. 만료 링크는 유효한 보존 출력에서 재발급                                 |

문제가 계속되면 설정 하단의 **오류 보고**와 로그에서 원인을 확인하세요. 토큰·쿠키·API 키·다운로드 링크를 이슈에 붙이지 말고, 앱·클라이언트 버전, 오류 문구, 재현 순서를 기록합니다.

<details>
<summary>개발자용: 연결 계약과 주요 도구</summary>

앱 관리 연결은 **HTTPS `/mcp` + OAuth/DCR + PKCE + 앱 내부 코드 승인**을 사용합니다. 일반 사용자는 환경변수나 토큰 파일을 만들 필요가 없습니다. 도구 목록과 스키마는 실행 중인 서버 및 승인 범위가 기준입니다.

| 단계           | 대표 도구                                                                                                                                   |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 서버·지원 기능 | `carrot_get_server_info`, `carrot_get_capabilities`                                                                                         |
| 대상 확인      | `carrot_list_works`, `carrot_list_chapters`, `carrot_get_chapter`, `carrot_get_page_blocks`                                                 |
| 완성 번역 시작 | `carrot_get_translation_guide` — 문맥·원본·식자·이미지 경로·최종 검수 절차 조회                                                             |
| 번역문 수정    | `carrot_update_translations`, `carrot_preview_translation_batch`                                                                            |
| 식자 확인      | `carrot_list_fonts`, `carrot_get_font_samples`, `carrot_render_page_preview`                                                                |
| 작품 폰트      | `carrot_get_work_typography`, `carrot_preview_work_typography`, `carrot_apply_work_typography`                                              |
| 생성 글자 보정 | `carrot_prepare_lettering_batch`의 `generated-touchup`, `carrot_get_sound_effect_candidates`, `carrot_touchup_sound_effect_candidate`       |
| 작업 추적      | `carrot_get_job`, `carrot_cancel_job`                                                                                                       |
| 출력           | `carrot_preflight_pages_export`, `carrot_export_pages_images`, `carrot_export_pages_psd`, `carrot_create_export_zip`, `carrot_get_job_file` |

편집은 도구 스키마가 요구하는 최신 revision·미리보기·요청 ID를 사용합니다. 작업 상태 조회는 파일을 자동 첨부하지 않습니다. 출력 파일은 명시적으로 조회하며 페이지 이미지 출력은 한 화의 1~50페이지 단위입니다. 오래된 상태의 요청을 강제로 재시도하거나, 원본 미리보기를 완성 출력으로 취급하지 마세요.

전체 번역은 `carrot_get_translation_guide`로 시작하고 마지막에 같은 요청 범위로 다시 조회합니다. `completion`에는 현재 revision의 검수와 누락 항목이 표시됩니다. `generated-touchup.edits[].moves`는 자산/페이지 좌표를 구분하며, 자형 검사에서 반환하는 문제 영역은 합성 crop 좌표이므로 `inspectionGeometry`로 대응시킨 뒤 사용합니다.
