# v3.2.0

v3.1.1 대비 OpenCode GO 빠른 설정을 추가하고, 원문과 다른 말풍선에 번역이 들어가던 문제와 연결 말풍선 사이의 원문 잔여물을 개선했습니다. 번역·원문 제거 런타임과 앱 의존성도 업데이트했습니다.

## API 연결

- **설정 → 번역 → API → API 제공자 빠른 설정 → OpenCode GO**를 추가했습니다. API 키를 입력하면 DeepSeek V4.1 Flash의 주소·모델·세션 헤더·JSON 모드가 함께 설정됩니다.
- 사용자 지정 API에 대화별 세션 헤더와 실제 앱 이름·버전 식별을 지원합니다. 같은 페이지의 검수·번역·보정·재시도는 세션을 유지하고, 다른 페이지와 새 작업은 분리합니다.
- JSON Schema를 지원하지 않는 서비스에서 명시적인 JSON 모드를 사용할 수 있습니다. OpenCode GO 번역과 연결 시험에서 재현된 HTTP 400을 수정했습니다.
- 인증·권한·사용량 한도·일시적 속도 제한·이미지 미지원 오류를 구분하고, 일시적 제한에는 `Retry-After`를 반영합니다. 다른 모델이나 과금 주소로 자동 전환하지 않습니다.
- README에 Go 월 US$10 요금제와 API 키 발급·연결 방법을 추가했습니다. 서비스의 이용 범위와 검증 범위도 함께 안내합니다.

## 번역과 원문 제거

- 기존 Hayai OCR 블록을 유지하는 번역에서 원문·블록 ID·위치를 고정해, 번역문이 다른 말풍선에 연결되거나 기존 OCR과 어긋나는 문제를 수정했습니다.
- 전체 페이지 이미지를 함께 참조해 구어체·고유명사·후리가나와 장면 문맥을 반영하도록 번역 지침을 보강했습니다. 긴 숫자 오인식을 근거 없는 대사로 확대하는 응답을 검사하고, 복구되지 않은 결과는 검토 대상으로 남깁니다.
- 연결·겹침 말풍선의 원문 제거 범위를 식자용 분할 영역과 구분해, 경계 틈에 글자가 남는 문제를 개선했습니다. 선택하지 않은 인접 블록의 글자는 보호합니다.
- FLUX 효과음 지우기와 연결 말풍선 처리에서 마스크·합성 범위를 보정했습니다. 그림과 말풍선 바깥까지 지우는 것을 막는 제한을 유지합니다.
- 웹페이지 이미지 가져오기에서 일부 다운로드가 멈추면 전체 작업도 더 진행되지 않던 문제를 수정했습니다.

## 실행 환경과 호환성

- 내장 Codex를 **0.160.0**, Electron을 **44.5.1**, ONNX Runtime을 **1.30.0**으로 업데이트했습니다. FFmpeg와 지원하는 OCR·번역 런타임, npm·Rust 의존성 및 CI 도구도 갱신했습니다.
- Koharu 0.83.5 기반 원문 제거 엔진과 플랫폼별 런타임 설치·실행을 정비했습니다. CPU 실행이 불필요한 NVIDIA 설치에 의존하지 않도록 했습니다.
- 최신 llama.cpp·BeeLlama의 실행 옵션과 DFlash 계약에 맞췄습니다. `--no-mmap` 등의 기존 옵션 때문에 모델 시작이 실패하던 문제를 수정했습니다.
- Windows CUDA·AMD·Vulkan 및 Apple Silicon 실행 파일의 실제 명령행·로더 검증을 추가했습니다. macOS 첫 기동이 30초를 넘는 경우를 처리하고 실패 진단 로그를 보존합니다.
- RTX 20 계열을 위한 CUDA 12 경로와 SM75 자산 검증을 유지합니다. 최신 CUDA를 모든 GPU에 강제하지 않으며, 이번 검증이 모든 AMD·NVIDIA 실물 GPU의 동작 보증을 뜻하지는 않습니다.

## 검증 범위

- Gemma 12B·26B는 실제 앱의 OCR·번역 경로와 여러 작품 표본으로 블록 대응 및 번역 회귀를 검사했습니다. OpenCode GO는 50작품·50페이지에서 이미지 요청·JSON 응답·블록 대응을 확인했습니다.
- Windows·Apple Silicon 전체 검사와 네이티브 런타임 검사, macOS LaMa·FLUX 실제 CPU 추론을 실행했습니다. 표본 검증은 모든 작품의 오역·잔여물이 없다는 보증은 아닙니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.2.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.2.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
