# v3.2.1

macOS 설치 파일의 검증 과정에서 발생한 실패를 수정한 패치 릴리스입니다. OpenCode GO 빠른 설정과 번역·원문 제거 개선 등 [v3.2.0의 기능](v3.2.0.md)을 포함합니다.

## macOS 패키징과 검증

- Koharu 원문 제거 검증이 실제 앱과 동일한 실행 파일·인자·네이티브 런타임 설정을 사용하도록 수정했습니다. 이전 검증에서 빠졌던 런타임 옵션 때문에 패키징이 실패하던 문제를 해결했습니다.
- Electron에서 검증 프로세스의 진입점이 실행되지 않아 대기하던 문제를 수정하고, 실제 Electron 프로세스로 확인하는 회귀 테스트를 추가했습니다.
- 게시하지 않고도 정식 macOS 패키지와 런타임을 검증할 수 있는 CI 실행 옵션을 추가했습니다. 정식 릴리스의 태그·커밋·Windows 설치 파일 확인과 macOS 검증 기준은 유지합니다.

## CI 안정화

- MCP 연구 배치의 HTTP 응답 뒤 비동기로 저장되는 완료 상태를 충분히 기다리도록 테스트를 수정했습니다. 결과 상태와 저장 내용 검증은 그대로 유지합니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.2.1.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.2.1-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
