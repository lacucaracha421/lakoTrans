# v3.2.2

고해상도 페이지를 다룰 때 목록·보관함·자동 저장·폰트 분석에서 반복하던 작업을 줄이고, 자동 대사 크기 맞춤을 개선한 릴리스입니다. 편집 화면과 실제 출력은 원본 해상도를 유지합니다.

## 화면과 출력 일치

- Windows 화면 배율에 따라 세로 글자의 마지막 부분이 출력에서 옆 열로 넘어가던 문제를 고쳤습니다. 화면과 출력이 같은 줄바꿈과 글자 간격 계산을 사용합니다.
- PSD는 완성 이미지를 기본 표시하고, 개별 래스터와 편집 가능한 글자를 숨긴 그룹에 보존합니다. Photoshop이 편집용 글자를 다시 조판하더라도 처음 표시하는 완성 이미지에는 영향을 주지 않습니다.
- PSD 글자별 이미지에서도 페이지 전체의 대사 크기 맞춤을 유지합니다. 편집용 글자에는 실제 렌더 크기와 줄바꿈, 폰트 파일의 PostScript 이름, 올바른 장평·외곽선 값을 기록합니다. 편집용 글자를 켜면 설치 글꼴과 Photoshop의 조판에 따라 세부 배치가 달라질 수 있습니다.

## 이미지와 보관함

- 페이지 목록, 페이지 선택기, 작업 진행 버튼과 기록에 화면 크기·배율에 맞는 썸네일을 사용합니다. 작은 썸네일에 고해상도 원본을 전달하던 낭비를 줄였습니다.
- 투명도와 이미지 회전 정보를 보존하며, 애니메이션·특수 색상 프로필 등 축소본의 동일성을 보장하기 어려운 이미지는 원본으로 표시합니다. 상세 뷰어와 효과음 편집 화면도 원본을 사용합니다.
- 블록 보관함은 화면 근처의 미리보기만 렌더링합니다. 키보드 포커스와 스크롤, 블록 편집 동작은 유지합니다.
- 작품·화 목록의 요약 정보를 제한된 캐시에 재사용하고, 내보낼 페이지를 선택할 때는 필요한 메타데이터만 읽습니다. 실제 출력 시에는 저장된 전체 페이지를 사용합니다.

## 저장과 편집

- 자동 저장 응답에서 변경한 페이지 중심으로 데이터를 전달해 큰 화의 반복 전송을 줄였습니다. 저장 충돌 검사와 실패 후 수정 내용 보존은 유지합니다.
- 화를 열 때 이미 알고 있는 작품 정보를 재사용하고, 분리 편집 패널에는 글꼴 계산에 불필요한 큰 이미지 데이터를 보내지 않습니다.
- 다중 글꼴 크기 조절과 조건 일괄 편집에서 같은 페이지 계산·조건 검색을 반복하지 않도록 개선했습니다.

## 자동 대사 크기와 폰트 분석

- 원문 크기가 비슷한 일반 대사의 자동 글꼴 크기를 페이지 안에서 더 일관되게 맞춥니다. 넘침이나 단어 끊김이 늘어나는 조정은 적용하지 않으며 수동 서식은 유지합니다.
- 좁은 말풍선의 자동 글자 크기와 줄 배치 계산을 개선하고, 편집 화면·분리 패널·출력에서 같은 결과를 사용하도록 맞췄습니다.
- CPU 폰트 분석에 선택적 글자 검증 가속을 적용했습니다. 확실하게 일치하는 글자만 빠른 경로를 사용하고 불확실한 입력이나 준비 실패는 기존 검증으로 돌아갑니다.
- 충분한 여유 메모리가 있는 NVIDIA GPU의 폰트 분석 배치를 조정하고, 페이지 디코딩·글자 crop·중간 이미지 생성을 재사용하거나 생략해 반복 작업을 줄였습니다. 저용량 GPU와 다른 실행 환경의 기존 배치 정책은 유지합니다.
- 보호 영역 crop과 마스크 미리보기에서 불필요한 전체 페이지 PNG 변환을 줄이고, 출력 중 커스텀 폰트 목록의 반복 조회를 줄였습니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.2.2.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.2.2-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
