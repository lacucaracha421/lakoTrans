# v3.3.0

앱 안에서 Codex·Claude와 대화하며 번역·식자·검수를 이어갈 수 있습니다. 외부 MCP 연결과 정밀 검수도 보강했습니다.

## 채팅 번역과 Claude Code

- 오른쪽 패널에 채팅을 추가했습니다. `채팅으로 번역`, 보관함 채팅 아이콘, 명령 검색에서 열고 현재 작품·화·페이지·선택 블록을 참고해 작업을 요청할 수 있습니다.
- 대화 기록과 참고 이미지, 모델 선택을 저장합니다. 작품 이동과 앱 재시작 후 대화를 이어가고, 새 대화·문맥 압축·추가 지시·중지를 사용할 수 있습니다. 도구 결과와 이미지 미리보기, 검수 상태도 대화에 표시합니다.
- 내장 Claude Code 런타임으로 Claude 구독·Console 계정 로그인과 모델 선택을 지원합니다. 일반 번역·문맥 조사와 채팅에서 사용할 수 있으며, 채팅의 Codex·Claude 선택은 일반 번역 설정과 별도로 관리됩니다.
- 채팅은 앱의 기존 MCP 도구를 내부 연결로 사용합니다. Tailscale이나 외부 MCP 설정 없이 시작할 수 있으며, 실제 작업에는 해당 계정과 앱 엔진 준비가 필요합니다.

## MCP 번역·식자·검수

- 원본 확인, 실제 폰트 견본, 작품별 서식, 원문 제거와 최종 렌더의 검수 근거를 현재 페이지 상태와 함께 확인합니다. 빠진 근거·오래된 검수·미검수 범위를 정밀 완료와 구분합니다.
- 생성 효과음의 글자 모양과 합성 결과 검사를 보강했습니다. 생성 글자에 문제가 남으면 원본과 확정 문구를 보존하고 사용자 보정 대기로 남길 수 있습니다. 요청 없는 자동 획 보정·자모 이동은 기본 작업에서 제외합니다.
- Claude와 기타 MCP 클라이언트의 말풍선 배치·줄바꿈·원문 보존 안내를 개선하고, Codex 연결을 기타 클라이언트로 잘못 분류하던 문제를 수정했습니다. 실제 렌더의 배치 관측 정보를 제공하되 수동 배치를 일괄 차단하지 않습니다.
- OpenCode·기타 MCP 앱의 연결 도움말, 이미지 전달과 작업 알림·복구 흐름을 보강했습니다. README에 내부 채팅과 외부 MCP 사용법을 추가했습니다.
- 정밀 검수는 근거와 누락을 확인하는 기능이며, 번역·미적 품질이나 모든 오자의 검출을 보장하지 않습니다.

## 연결과 오류 수정

- OpenCode GO API 빠른 설정에서 제공 모델 목록을 확인하고 선택할 수 있도록 개선했습니다.
- 웹 원고 가져오기 중 팝업·화면 이동이 수집 작업을 방해하지 않도록 탐색 보호를 추가했습니다.
- Flux 런타임 오류에 종료 코드를 표시하고 긴 스택 로그 앞의 최초 오류 원인을 보존합니다. ROCm/HIP라는 문구만으로 GPU나 드라이버 문제라고 단정하던 메시지도 수정했습니다([#147](https://github.com/ucx0204/CarrotMangaTranslator/issues/147)). 이 변경은 진단 개선이며, 신고된 Radeon 실행 실패의 원인 해결이나 해당 GPU의 동작 검증을 뜻하지 않습니다.

## 설치 파일·서명

- **Windows 10/11 x64:** `CarrotMangaTranslator-Setup-v3.3.0.exe` — 코드 서명 없음.
- **Apple Silicon macOS 14 이상:** `CarrotMangaTranslator-3.3.0-macOS-arm64.dmg` / `.zip` — ad-hoc 서명, Apple 공증 없음. Intel Mac은 지원하지 않습니다.
- 모델·런타임은 앱에서 별도로 내려받습니다. 플랫폼별 `SHA256SUMS`와 provenance 파일에서 설치 파일 해시와 빌드 커밋을 확인할 수 있습니다.
