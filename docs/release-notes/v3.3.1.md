# v3.3.1

대화 전환 때 채팅이 겹치거나 잘리는 문제와 설치판 글꼴 견본 오류를 수정했습니다. 앱 채팅과 외부 MCP의 번역·이미지 도구 선택·검수 지침을 공통화했습니다.

## 채팅과 글꼴 오류 수정

- 대화 목록을 오갈 때 이전 대화의 본문과 입력창이 화면에 남던 문제를 수정했습니다. 대화 초안은 유지하면서 본문과 입력창을 함께 전환합니다.
- 설치판에 포함된 폰트의 파일 검증 때문에 글꼴 견본 도구가 `revision_conflict`를 반복하던 문제를 수정했습니다. 실제 폰트 바이트와 설치 패키지 변경 여부를 검증합니다.
- Codex·Claude 도구 실패의 상세 메시지를 대화 기록에 보존합니다. 도구 목록을 펼쳐 원인을 확인할 수 있습니다.
- 비동기 편집의 공개 오류 설명을 채팅·MCP 작업 조회에도 전달합니다. 엔진 불일치에는 현재/요청 엔진과 올바른 작업별 선택 도구를 안내합니다. 내부 파일·모델 오류의 원문은 노출하지 않습니다.
- 작업별 로컬 엔진 선택값이 작업 기록 저장 단계에서 거부되던 오류를 수정했습니다. 선택한 엔진은 재시작·실패 작업 재시도에도 유지됩니다.
- 복구 기록 256개에서 편집 저장이 막히던 문제를 수정했습니다. 기존 기록을 보존하면서 한도를 4,096개로 늘리고, 1 GiB 용량 한도와 7일 보관 기간은 유지합니다. 한도 초과를 일시적인 사용 중 오류로 알리지 않으며, 원문 제거·이미지 편집 전에 저장 여유를 확인합니다.

## 앱 채팅과 외부 MCP의 공통 작업 기준

- 같은 번역 지침을 직접 공유합니다. 원본 확대 확인, 원문 전체의 제거 범위, 한국어 배치, 실제 폰트 견본, 제거 후 배경과 최종 식자 검수를 양쪽에 동일하게 안내합니다.
- 작은 가로 글씨로 큰 효과음을 일괄 대체하지 않고 원문의 크기·방향·윤곽·연출을 확인하도록 보강했습니다. 대표 페이지를 실제 렌더까지 검수한 뒤 나머지 페이지로 확장합니다.
- 사용자가 지정한 엔진·모델을 우선합니다. 미지정 시 단순 배경은 단색 칠하기/AOT, 일반 원문 제거는 FLUX, 복잡한 복원·그림형 글자는 앱 이미지 생성을 검토합니다. 외부 MCP에도 같은 기본값을 적용합니다.
- ChatGPT 구독과 현재 Codex 사용량을 읽는 도구를 추가했습니다. Pro에는 더 넉넉한 생성 예산을, Plus 등에는 보수적인 예산을 안내하며, 사용량이 부족하면 자동 생성을 피합니다. 이는 이미지 생성 잔여 횟수 조회가 아니며 조회 불가는 알 수 없는 상태로 처리합니다.
- MCP 원문 제거에서 작업별 로컬 엔진을 선택할 수 있습니다. 전역 설정은 바꾸지 않습니다. 같은 페이지의 영역은 한 작업으로 묶도록 안내합니다.

제거 성공은 시각적 검수 완료와 다릅니다. 이미 저장된 좁은 제거 영역이나 미검수 결과를 자동으로 덮어쓰지는 않습니다. 개선된 공통 지침과 검증이 모든 모델 실행의 번역·미적 결과 일치를 보장하는 것은 아닙니다.
